# Site public DeepAMC

Sources statiques du site officiel [deepamc.app](https://deepamc.app).

Le site présente DeepAMC, ses offres, ses téléchargements et sa documentation
publique. Il ne contient ni secret serveur, ni donnée de compte, ni donnée
académique.

- Backend : `https://api.deepamc.app`
- Administration : `https://admin.deepamc.app`
- Site public : `https://deepamc.app`

Les applications distribuables sont publiées dans les Releases de ce dépôt.
Le paquet Desktop est proposé directement sur la page de téléchargement. L’APK
Android signé est distribué par SOFTNEUR dans le cadre de la diffusion contrôlée
de DeepAMC Mobile.
