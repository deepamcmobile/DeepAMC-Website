Installer DeepAMC Desktop

  1. Extraire l’archive téléchargée.
  2. Ouvrir un terminal dans le dossier extrait.
  3. Exécuter chmod +x install.sh && ./install.sh.

Prérequis : Python 3, Tkinter, Cryptography et Poppler. Sous Windows 11, l’installation s’effectue dans Ubuntu via WSL.
