Installer DeepAMC Desktop

  1. Vérifiez que vous utilisez Ubuntu, Linux compatible Debian ou Ubuntu dans WSL sous Windows.
  2. Téléchargez le paquet Debian ci-dessus, puis ouvrez Ubuntu et accédez au dossier du fichier.
  3. Exécutez sudo apt install ./deepamc-desktop_0.2.7_all.deb.

Aucune dépendance à gérer manuellement : apt installe automatiquement Python 3, Tkinter, Cryptography et Poppler. Auto Multiple Choice est proposé comme composant recommandé.
