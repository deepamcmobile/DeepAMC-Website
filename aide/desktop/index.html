Installer DeepAMC Desktop sous Windows

Utilisez l’installateur natif DeepAMC-Desktop-0.2.0-Windows-Native-Setup.exe sur Windows 10 ou 11, en 64 bits. L’activation de la virtualisation et une connexion Internet sont nécessaires pour installer les composants Ubuntu. Sur Windows 10, l’ouverture des fenêtres AMC dépend aussi de la disponibilité de l’affichage graphique WSLg.

  1. Lancez l’installateur. Si Windows demande une autorisation administrateur pour activer WSL, validez-la.
  2. Si l’installateur demande un redémarrage, redémarrez Windows puis reconnectez-vous au même compte. La configuration reprend à l’ouverture de session.
  3. Ouvrez DeepAMC Desktop depuis le menu Démarrer. DeepAMC s’exécute sous Windows et Auto Multiple Choice (AMC) 1.7 s’exécute dans Ubuntu 22.04 via WSL.
  4. Si la configuration est interrompue, lancez Configurer AMC depuis le menu Démarrer. Le journal se trouve dans %LOCALAPPDATA%\DeepAMC\configuration-amc.log.

Pour mettre à jour une installation Windows portant déjà le numéro 0.2.0, fermez DeepAMC Desktop avant de lancer le nouvel installateur.

Préparer un sujet QCM

  1. Dans Compte et licence, connectez-vous et vérifiez que l’ordinateur dispose du droit d’export AMC. Ce droit donne aussi accès à l’éditeur.
  2. Ouvrez Préparer un sujet QCM. Adaptez les exemples du modèle à votre épreuve. Indiquez le nombre de chiffres de l’INE demandé sur la copie, ou saisissez 0 pour retirer la grille.
  3. Dans En-tête, logo et paramètres AMC, renseignez l’établissement, la filière, la matière, l’année et les autres informations de l’épreuve. Ajoutez au besoin le logo de l’établissement au format PNG, JPEG ou PDF. Pour une feuille de réponses séparée, choisissez si l’en-tête doit y être répété.
  4. Dans Barèmes et feuille de réponses, cliquez sur Aide près de chaque barème par défaut. Utilisez un point dans les décimales, par exemple 0.25. La note maximale de l’en-tête est imprimée sur le sujet. Le calcul des notes dépend des barèmes.
  5. Cliquez sur Nouvelle question. Ajoutez au moins deux choix et marquez les bonnes réponses. Pour une question simple, marquez une seule bonne réponse. Les commandes Image, Formule LaTeX et Code / algorithme insèrent du contenu dans l’énoncé. Les images ajoutées peuvent être prévisualisées, remplacées ou retirées.
  6. Dans la liste, sélectionnez une question pour la consulter en lecture seule. Cliquez sur Modifier la question pour éditer ses champs, puis sur Valider la question pour appliquer les changements.
  7. Cliquez sur Enregistrer ou utilisez Ctrl+S. Au premier enregistrement, choisissez le dossier parent. Sous Windows, sélectionnez Dossiers Windows ou la distribution Ubuntu proposée, puis cliquez sur Parcourir…. Pour faire une copie du sujet avec son logo et ses images, utilisez Enregistrer sous… et donnez un nom au nouveau dossier.
  8. Pour reprendre le travail plus tard, cliquez sur Ouvrir un sujet DeepAMC et choisissez le fichier deepamc-subject.json. Pour compiler le sujet, cliquez sur Ouvrir dans AMC. Dans Préparation (Preparation), mettez à jour les documents et faites la détection des mises en page. Contrôlez le PDF et la feuille de réponses avant l’impression.

L’éditeur génère la source sujet.txt au format AMC-TXT. Vous pouvez aussi créer un sujet LaTeX directement dans AMC et utiliser le même parcours d’export une fois le projet compilé. Le bouton Lancer AMC est accessible depuis l’accueil.

Exporter un projet AMC vers DeepAMC Mobile

  1. Dans Desktop, ouvrez Exporter vers Mobile et cliquez sur Parcourir…. Sous Windows, ce bouton propose les dossiers Windows et les distributions Ubuntu détectées. Sélectionnez le dossier du projet AMC compilé.
  2. Cliquez sur Analyser le projet. Dans Compatibilité, vérifiez la version AMC, les exemplaires, les pages et les questions notées. La grille INE apparaît séparément dans le diagnostic.
  3. Cliquez sur Préparer l’export, choisissez la destination, puis cliquez sur Générer le fichier .deepamc.
  4. Transférez ce fichier vers le téléphone et importez-le dans DeepAMC Mobile. Scannez ou importez les copies, vérifiez celles qui nécessitent une intervention et associez les copies à la liste des étudiants si vous souhaitez des rapports nominatifs.
  5. Depuis Mobile, exportez les résultats au format Projet AMC pour obtenir le fichier .deepamc-results.

Réimporter les résultats mobiles et annoter les copies

  1. Fermez le projet dans AMC, puis ouvrez Importer les résultats dans DeepAMC Desktop.
  2. Sélectionnez le dossier du même projet AMC que celui utilisé pour préparer le paquet Mobile, puis le fichier .deepamc-results.
  3. Cliquez sur Vérifier la compatibilité et contrôlez le résumé, notamment les copies qui seront remplacées lors d’une réimportation. Cliquez ensuite sur Importer et créer une sauvegarde.
  4. Lorsque le paquet contient une liste étudiante exploitable, DeepAMC la place dans le dossier du projet et configure AMC pour utiliser le même identifiant que les associations de copies. Le dossier deepamc-backups/ contient la sauvegarde de l’import, notamment le fichier de configuration précédent si DeepAMC l’a modifié.
  5. Rouvrez le projet dans AMC. Passez directement à Rapport (Reports), puis cliquez sur Annoter les copies (Annotate papers). Utilisez Voir (Look) pour ouvrir le dossier des résultats, ou ouvrez cr/corrections/pdf/ depuis le dossier du projet.

Si le nom ou le prénom manque

  • Dans Notation → Identification des étudiants (Marking → Students identification), vérifiez que la liste du projet est deepamc-students.csv et que l’identifiant unique correspond à la colonne de cette liste. Selon le projet, cette colonne peut s’appeler INE AMC ou student_code.
  • Si seules certaines copies restent sans nom, vérifiez que leur identifiant figure dans la liste et qu’il correspond exactement à celui de la copie, y compris les zéros en tête. Après correction, relancez Annoter les copies pour produire un nouveau PDF.
  • Si Look signale une erreur avec Nautilus sous WSL, ouvrez directement le dossier cr/corrections/pdf/ depuis l’Explorateur Windows. L’erreur d’ouverture du dossier peut survenir après la génération du PDF.

Compte et licence

Le menu de navigation comprend un espace Compte et licence, commun à Mobile et Desktop. Le backend de production https://api.deepamc.app est configuré par défaut. Desktop ne contacte jamais le prestataire de paiement directement et ne contient aucune clé de paiement.

La consultation et le diagnostic des projets existants restent accessibles hors connexion. L’éditeur QCM et la génération d’un nouveau .deepamc exigent le droit d’export AMC. La réimportation d’un .deepamc-results exige le droit d’import AMC. Desktop vérifie ces droits via un jeton de licence signé pour l’ordinateur et utilisable hors ligne jusqu’à sa date d’expiration. Dans l’éditeur, la licence est vérifiée à l’ouverture et à l’enregistrement. En cas de refus pendant l’édition, la saisie reste à l’écran.

Lorsque l’interface est ouverte, Desktop surveille silencieusement la route réseau locale, sans interroger continuellement le backend. La licence est actualisée au démarrage si Internet est disponible et à chaque retour de connexion. Une indisponibilité transitoire conserve le dernier droit hors ligne valide : trois tentatives rapprochées sont effectuées, puis les nouvelles tentatives passent à un intervalle de cinq minutes.
